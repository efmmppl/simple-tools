# A 股实时行情悬浮窗设计

## 目标

构建一个独立运行的 Windows Electron 小程序，用于在桌面上持续显示 A 股自选列表行情。首版重点是轻量盯盘，不包含交易下单或复杂技术分析。

## 已确认范围

- 独立 Windows 程序，不依赖工具箱页面运行。
- 支持沪深股票和 ETF。
- 支持自选列表，可添加和删除股票。
- 每行显示名称、代码、现价、涨跌额、涨跌幅和行情时间。
- 默认每 5 秒刷新，允许设置 3-60 秒。
- 支持透明度调节、始终置顶、无边框拖动。
- 关闭窗口时隐藏到系统托盘，托盘菜单支持恢复、刷新、置顶切换和退出。
- 自选股、窗口位置、透明度、刷新间隔和置顶状态保存到本地。
- 输出 Windows 安装版和免安装便携版。

## 非目标

首版不实现 K 线、技术指标、买卖信号、价格预警、声音通知、云同步、登录、Level-2、逐笔成交或交易下单。

## 技术方案

采用 Electron + HTML/CSS/JS。原因是现有 `0710` 工具箱已使用相同前端技术，股票代码规范化和腾讯行情接口解析逻辑可以复用思路，同时 Electron 对置顶、透明、无边框窗口和系统托盘提供成熟支持。

主进程负责创建和管理窗口、托盘、窗口状态及 IPC；渲染进程负责列表界面、输入校验和设置交互。渲染进程不直接获得 Node.js 权限，仅通过预加载脚本暴露最小化的窗口控制 API。

## 界面结构

窗口采用紧凑的无边框布局：

- 标题栏左侧显示应用名称和拖动区域。
- 标题栏中部显示连接状态和最后更新时间。
- 标题栏右侧提供置顶、透明度、设置和隐藏按钮。
- 主区域显示自选股票行列表。
- 设置区域包含添加代码、刷新间隔和透明度控件。
- 空列表显示添加股票提示。

上涨和下跌颜色遵循 A 股习惯，涨跌颜色只表示行情方向，不产生投资建议。

## 数据流

1. 应用启动，主进程创建窗口，渲染进程读取本地配置。
2. 用户添加代码时进行格式规范化，并请求接口确认股票存在和获取名称。
3. 刷新任务将所有自选代码合并为一次批量行情请求。
4. 数据层解析名称、现价、昨收、涨跌额、涨跌幅和时间。
5. 渲染层更新对应行，并记录最后一次成功时间。
6. 配置变更立即持久化，刷新间隔变更立即重建定时器。

行情模块应独立于界面实现，便于未来替换数据源。现阶段沿用工具箱中腾讯行情接口的公开访问方式，但不把它视为券商级实时数据。

## 异常处理

- 请求超时、网络断开、限流或返回格式异常时保留上一次有效行情。
- 首次加载失败时显示可重试状态，不渲染虚假的价格。
- 顶部状态显示连接失败、更新时间或非交易时段提示。
- 非交易时段显示接口返回的最近数据时间，不伪造实时状态。
- 无效代码、重复代码和接口返回的未知代码在添加时给出明确错误。
- 应用退出前保存窗口位置、大小和用户设置。

## 本地数据

配置至少包含：

- 自选代码数组
- 刷新间隔
- 透明度
- 置顶状态
- 窗口位置和大小

配置只保存在本机，不包含账号、密码或交易凭证。

## 验证策略

- 单元测试覆盖代码规范化、行情批量解析、涨跌字段计算和异常数据处理。
- 手工验证添加、删除、重复代码、定时刷新和配置重启恢复。
- 手工验证置顶、透明度、拖动、无边框按钮、托盘隐藏/恢复/退出。
- 验证网络断开后保留旧值，网络恢复后继续刷新。
- 验证不同 DPI、窗口尺寸和多显示器位置下的显示行为。
- 使用 Electron Builder 生成 Windows 安装版与便携版，并在干净环境启动验证。

## 风险与后续扩展

公开行情接口可能发生字段或访问策略变化，因此请求和解析逻辑必须集中在独立模块中。后续如增加预警、声音通知或 K 线，应作为独立功能扩展，不改变基础行情刷新接口。
