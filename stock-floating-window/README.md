# Stock Floating Window

一个显示 A 股实时行情的 Windows 桌面悬浮窗。行情仅供信息参考，不构成投资建议。

## 安装

运行安装程序并按向导完成安装。安装后从开始菜单或桌面快捷方式启动应用。

## 便携版

直接运行 `Stock Floating Window.exe`，无需安装。配置保存在当前 Windows 用户的 Electron 应用数据目录中，因此便携版不会把配置写入程序目录。

## 使用

- 在设置区域输入六位 A 股代码，例如 `600519` 或 `000858`，点击添加。
- 代码以 `6` 或 `5` 开头时按上海市场处理，以 `0`、`1`、`2` 或 `3` 开头时按深圳市场处理。
- 点击行情行上的“移除”删除股票。
- 刷新间隔可设置为 3 到 60 秒，默认每 5 秒刷新。
- 透明度可设置为 35% 到 100%。
- 可切换“始终置顶”，并拖动无边框窗口到需要的位置。

## 托盘

关闭窗口会将其隐藏到系统托盘，不会退出应用。右键托盘图标可以显示窗口、立即刷新、切换始终置顶或退出应用。托盘菜单中的始终置顶状态会与窗口设置同步。

## 数据说明

行情来自腾讯行情接口，网络不可用或接口返回错误时，窗口会保留最近一次成功获取的数据并提示错误。接口、网络和市场状态可能导致数据延迟、缺失或不可用。

本应用不提供交易、账户、预警或技术分析功能。所有 quote data 仅供信息参考，不构成任何投资、买卖或其他金融决策建议。
